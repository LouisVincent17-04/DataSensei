# Instructor Guide: Student Model Development

Open **Student Model Development** from the instructor sidebar. Only datasets, jobs, and models explicitly linked to classes owned by the signed-in instructor are included. A student’s private experiment without a class association remains inaccessible to instructors and other students.

The dashboard provides:

- participating student count;
- class-linked uploaded dataset count and measured quality scores;
- queued, running, completed, and failed training totals;
- best-performing models using task-appropriate metrics;
- student, class, algorithm, active version, and performance details;
- recent progress and failure messages;
- recurring error summaries for identifying common mistakes.

Use the results as learning evidence rather than treating one test split as a final ranking. Ask students to justify their target and features, compare cross-validation with holdout performance, inspect class imbalance and residuals, explain feature influence, and distinguish preprocessing gains from algorithm gains.

The instructor dashboard is observational. It does not permit an instructor to overwrite a student artifact, activate a student version, or access private unlinked uploads. System benchmark models remain globally read-only.
